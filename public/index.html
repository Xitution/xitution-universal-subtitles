Wo hinterlege ich den ElevenLabs-API-Schlüssel?

Bei ElevenLabs unter Developers → API Keys einen Schlüssel mit Dubbing-Berechtigung erstellen. Dann im bestehenden Render-Dienst unter Environment → Add Environment Variable ergänzen:

ELEVENLABS_API_KEY = dein ElevenLabs-Schlüssel

Speichern und neu bereitstellen. OPENAI_API_KEY bleibt für die Untertitel bestehen. Keine API-Schlüssel in diese Seite, GitHub oder den Chat eintragen.
